# Explorateur de mobilité 🧭

Appli web qui affiche les zones atteignables à pied, à vélo et en voiture
depuis n'importe quel point, en 5 à 60 minutes.

## 🚀 Essayer
👉 https://jules-caille.github.io/isochrones/

## ✨ Fonctionnalités
- Recherche par adresse (Nominatim/Photon)
- Zones écrêtées sans mélange de couleurs (priorité : pied > vélo > voiture)
- Outil règle de mesure, légende interactive, 2 fonds de carte
- Diagnostic intégré des services
- Responsive : ordinateur, tablette, smartphone

## 🛠️ Technologies
Leaflet, Turf.js, API Valhalla, API Nominatim/Photon
